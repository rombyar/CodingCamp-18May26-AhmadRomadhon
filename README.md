# Life Dashboard — Ahmad Romadhon

> **Coding Camp Software Engineering** — Batch 18 May 2026

A personal productivity web app built with pure HTML, CSS, and Vanilla JavaScript — no frameworks, no backend.

🌐 **Live Demo:** [rombyar.github.io/CodingCamp-18May26-AhmadRomadhon](https://rombyar.github.io/CodingCamp-18May26-AhmadRomadhon/)

---

## Features

### MVP
- **Greeting Section** — Real-time clock, full date, and dynamic greeting based on time of day
- **Focus Timer** — 25-minute Pomodoro timer with Start / Pause / Reset and a progress bar
- **To-Do List** — Add, edit, mark as done, and delete tasks; persisted in Local Storage
- **Quick Links** — Add and remove shortcut links to favourite websites; persisted in Local Storage

### Challenges Implemented ⭐
1. **Light / Dark Mode** — Toggle button in the header; preference saved to Local Storage
2. **Custom Name in Greeting** — Enter your name once; shown in the greeting message
3. **Prevent Duplicate Tasks** — Validation blocks adding or editing a task to a name that already exists
